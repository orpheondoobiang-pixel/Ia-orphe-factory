# IA Orphe Factory — Android Demo

Version 1.0.0 — démonstration installable.

## Ce que contient cette version
- Interface Android verticale premium bleu nuit / bleu électrique / violet.
- Écran d'accueil IA Orphe Factory.
- Saisie d'une idée.
- Parcours de démonstration :
  1. Idée
  2. Script
  3. Scènes
  4. Voix
  5. Sous-titres
  6. Vidéo
- Aucun service externe requis pour l'interface de démonstration.
- Aucun logo, branding ou interface d'une plateforme sociale.

## Important
Cette version est une **maquette fonctionnelle de démonstration**. Les boutons simulent le workflow ; ils ne connectent pas encore de véritables modèles IA, synthèse vocale ou moteur de rendu vidéo.

## Générer l'APK
1. Ouvrir le dossier dans Android Studio.
2. Laisser Android Studio synchroniser Gradle.
3. Choisir `Build > Build APK(s)`.
4. L'APK debug sera générée dans :
   `app/build/outputs/apk/debug/app-debug.apk`

Application ID :
`com.orphe.factory.debug` pour la variante debug.

Application release :
`com.orphe.factory`
